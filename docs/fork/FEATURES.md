# Feature defaults

These are fresh-profile and fresh-CMake-cache defaults, not a migration of
existing preferences. Core Twitch chat and 7TV/BTTV/FFZ emotes stay enabled.

| Feature                  | Risk / tradeoff                                                                                                                  | Decision                                                 | Control and evidence                                                                                                                                                                                                                                                                                                          |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lua plugins              | Third-party code can read chat and request network/filesystem permissions; alpha surface                                         | Build option off                                         | `CHATTERINO_PLUGINS=OFF` in [CMakeLists.txt](../../CMakeLists.txt); `pluginsEnabled=false` remains the runtime gate.                                                                                                                                                                                                          |
| Kick                     | Outside the Twitch/YouTube scope; [KickApi.cpp](../../src/providers/kick/KickApi.cpp) mixes public API and private web endpoints | Recommend off; not implemented                           | No disable switch: `KickConnectionPreference::Default` means both transports. Hide/gate provider in a separate change; changing this enum default would not disable it.                                                                                                                                                       |
| Image uploader           | Sends pasted files to a configured host                                                                                          | Off by default (already)                                 | `imageUploaderEnabled=false`, blank destination, `askOnImageUpload=true` in [Settings.hpp](../../src/singletons/Settings.hpp); importing a preset enables uploads.                                                                                                                                                            |
| Browser native messaging | Local IPC can select/join channels; broad attachment increases process access                                                    | Keep browser integration; broad attachment off (already) | `attachExtensionToAnyProcess=false` restricts Windows attachment to listed browsers in [AttachedWindow.cpp](../../src/widgets/AttachedWindow.cpp). Native host registration/IPC still run; this setting does not disable the extension.                                                                                       |
| Streamlink               | Starts an external executable with configurable arguments; its provider APIs are outside this audit                              | Keep explicit user action                                | [StreamLink.cpp](../../src/util/StreamLink.cpp) runs on commands, menu actions or configured link/notification clicks; no launch at startup. Use a trusted executable.                                                                                                                                                        |
| Crashpad                 | Local dumps and arguments may contain sensitive data                                                                             | Build option off (already)                               | `BUILD_WITH_CRASHPAD=OFF`; [CrashHandler.cpp](../../src/singletons/CrashHandler.cpp) passes an empty upload URL if enabled. Local crash recovery remains.                                                                                                                                                                     |
| Link resolver            | Sends hovered URLs to a third-party service                                                                                      | Off by default (already)                                 | `linkInfoTooltip=false`, `unshortLinks=false`; [LinkResolver.cpp](../../src/providers/links/LinkResolver.cpp) checks the tooltip gate before requesting.                                                                                                                                                                      |
| Spellcheck               | Local dictionary parsing adds a dependency; no remote checking in this implementation                                            | Build option off (already); keep optional                | `CHATTERINO_SPELLCHECK=OFF`, `enableSpellChecking=false`; [SpellChecker.cpp](../../src/controllers/spellcheck/SpellChecker.cpp) uses local Hunspell dictionaries.                                                                                                                                                             |
| IVR sub age              | Discloses target user/channel to IVR                                                                                             | Off by default (already)                                 | `showSubageInUserCard=false`; [IvrApi.cpp](../../src/providers/IvrApi.cpp) checks it before requesting.                                                                                                                                                                                                                       |
| Recent messages          | Discloses joined channel to a history service                                                                                    | Off by default (already)                                 | `loadTwitchMessageHistoryOnConnect=false`; connect/reconnect paths in [TwitchChannel.cpp](../../src/providers/twitch/TwitchChannel.cpp) check it.                                                                                                                                                                             |
| 7TV presence             | Reports account/channel activity                                                                                                 | Off by default (already)                                 | `sendSevenTVActivity=false`; Twitch/Kick presence paths check it. Event API and emotes remain enabled.                                                                                                                                                                                                                        |
| BTTV presence            | `broadcast_me` reports account/channel activity                                                                                  | Off by default; send gates fixed here                    | `sendBTTVActivity=false`; [BttvLiveUpdates.cpp](../../src/providers/bttv/BttvLiveUpdates.cpp) skips initial presence, and [BttvLiveUpdateClient.cpp](../../src/providers/bttv/liveupdates/BttvLiveUpdateClient.cpp) rechecks consent for direct and queued/replayed sends. Public channel emote subscriptions remain enabled. |

Build defaults are not release guarantees: the paused upstream
[build workflow](../../.github/workflows/build.yml) explicitly enables plugins
in several Linux jobs and Crashpad/spellcheck in Windows jobs; macOS enables
spellcheck too. Review these overrides before re-enabling CI or releasing.
Existing CMake caches and saved settings retain their chosen values.

No Twitch GQL endpoint was found in `src/` during this review. The inherited
[default OAuth client ID helper](../../src/providers/twitch/TwitchCommon.hpp)
has no callers in `src/`; login still opens the upstream website in
[LoginDialog.cpp](../../src/widgets/dialogs/LoginDialog.cpp). Review the fork's
OAuth app ownership and login flow before release. This table does not certify
every inherited feature as using official APIs. See [network services](NETWORK.md).
