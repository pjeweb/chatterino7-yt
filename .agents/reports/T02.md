## Summary

The draft script is finished. Its core is now pure functions with no git:
`added_hosts(diff_text)`, `documented_hosts(markdown)`, `undocumented()` and
`format_report()`. Only `main()` calls git. It has 12 stdlib unittest tests
and a CI workflow. All of it passes locally, and a deliberate violation fails
with each `file:line` listed.

Rules (they're also in the script docstring and in the NETWORK.md intro):

- What counts: the host of every `http(s)://` / `ws(s)://` URL in lines
  **added** under `src/` between `merge-base(HEAD, upstream/chatterino7)` and
  `HEAD`.
- A host passes if NETWORK.md has it in backticks (`host`, `host/path` or
  `scheme://host`), or if it's in `LINK_ONLY`.
- **Matching is exact.** `evil.api.twitch.tv` fails even though
  `api.twitch.tv` is documented, and `twitch.tv` fails too.
- Ignored: removed lines, context lines, comment-only lines (`//`, `/*`,
  `*`, including after a UTF-8 BOM), `localhost` and loopback IPs. Other IP
  literals are checked.
- Exit codes: 0 = OK, 1 = undocumented hosts (grouped by host, with
  `file:line`), 2 = git error (for example a missing upstream ref or a shallow
  clone), with a hint showing the fetch command.

## Decisions / not done

- **Removed `github.com` from `LINK_ONLY`.** The planned Sparkle/WinSparkle
  appcast may be served from GitHub releases. That is a real fetch and should
  be documented, not allowlisted. The cost: a fork-added UI link to
  github.com now needs a NETWORK.md entry, or the supervisor puts it back in
  the allowlist.
- On PRs the check covers the **whole fork diff** against upstream, not just
  the PR's own changes. That matches the spec, but it means an existing
  violation on `chatterino7` would fail every PR.
- Only committed changes (`HEAD`) are checked, not the working tree, so
  results are deterministic and match CI.
- Known gaps (it's a tripwire): hosts built at runtime, scheme-less host
  strings (`QUrl::setHost("x")`), placeholders inside hosts
  (`https://%1.cdn.x`), `user@host` URLs and non-ASCII hosts are not
  detected. Upstream `src/` has no placeholder-in-host URLs today.
- Did not tick the ROADMAP phase 1 checkbox, to avoid conflicts with other
  workers. The supervisor can tick it when merging.
- Only `src/` is scanned, per the spec. `resources/` is not.
